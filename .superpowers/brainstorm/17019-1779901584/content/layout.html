B. Cards in columns (one card per variant)

Each variant reads as a coherent document, top-to-bottom. Easier to "read one model in full". Harder to spot per-field disagreements because your eye has to jump across 4 columns at different vertical offsets. Scales worse than matrix beyond ~3 variants.

Same matrix as A, but with two switches: prompt-version filter (default v2; can show v1 too) and view mode (rendered / JSON / diff-only).
